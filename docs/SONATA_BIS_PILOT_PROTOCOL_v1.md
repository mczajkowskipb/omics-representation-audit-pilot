# SONATA BIS PILOT PROTOCOL v1.0

**Working title:** Source-only selection of value, relational and hybrid representations for transportable omics clustering  
**Status:** PROPOSED — freeze after smoke tests  
**Owner:** Marcin Czajkowski  
**Date:** 2026-08-11  
**Primary goal:** preliminary evidence for SONATA BIS  
**Implementation mode:** Python-first, deterministic CPU reference implementation  
**Explicit exclusions:** fuzzy clustering, evolutionary algorithms, deep learning, federated learning, CUDA/GPU, universal RelCore platform

---

## 1. Executive decision

The pilot will test a narrow, falsifiable question:

> Can diagnostics computed exclusively on a source cohort identify whether a value, relational or hybrid representation will best preserve biologically relevant clustering structure in perturbed and independent data?

The pilot must distinguish four outcomes:

```text
VALUE
RELATIONAL
HYBRID
NO_STABLE_STRUCTURE
```

`UNCERTAIN` is not a fifth representation. It is a confidence flag attached when the selected outcome changes too frequently across source resamples.

The pilot is not intended to implement the complete SONATA BIS project. In particular:

- representation selection is tested before building sophisticated relational regions;
- a simple hybrid distance is used as a benchmark, not claimed as the main innovation;
- direct sparse relational regions are added only after the representation audit works;
- anchor-restricted candidate generation is added only after direct regions work;
- anchor sets are deferred unless single-anchor restriction gives a clear computational or stability benefit.

---

## 2. Questions to be answered

### Q1. Controlled regimes

Can the source-only audit distinguish datasets generated by:

1. magnitude/value signal;
2. relative-order signal;
3. complementary value and relative-order signals;
4. no reproducible cluster signal?

### Q2. Representation selection

Does the representation chosen without target data achieve target performance close to the best representation selected retrospectively by an oracle?

### Q3. Real external transfer

Does a source-fitted and frozen representation/model preserve assignments when transferred between independent gene-expression cohorts?

### Q4. Direct relational regions

Does iterative direct learning of sparse relational regions produce more stable and/or shorter profiles than:

```text
ordinary clustering → post-hoc relational profile extraction
```

### Q5. Anchors

Can anchor-restricted candidate generation reduce computation and redundancy without material loss of external performance?

---

## 3. Primary and secondary hypotheses

### H1 — representation regimes

Value, relational and hybrid representations have distinct domains of competence that can be generated under controlled conditions and observed in real omics datasets.

### H2 — source-only prediction

Source-only perturbation stability and held-out prediction strength predict which representation has the smallest external-transfer regret.

### H3 — abstention

Null or technically dominated data can be identified as lacking stable structure, instead of always producing a forced clustering.

### H4 — direct regions

Direct refinement of sparse relational regions improves profile stability or compression compared with post-hoc profile extraction.

### H5 — anchors

Anchor restriction reduces the number of evaluated relational candidates and runtime while preserving most of the transferable structure.

H5 is deliberately non-essential. Failure of H5 does not invalidate H1–H4.

## 5. Experimental hierarchy

The pilot has five sequential levels. A later level cannot delay or invalidate an earlier result.

### Level 0 — correctness and golden tests

Purpose:

- establish correct representation semantics;
- eliminate leakage;
- guarantee deterministic execution.

No scientific claim is made at this level.

### Level 1 — controlled source/target simulations

Purpose:

- show that different representations win under different known regimes;
- calibrate null thresholds;
- test source-only representation selection;
- quantify selection regret.

This is the main causal evidence.

### Level 2 — existing real datasets, within-dataset validation

Purpose:

- verify behavior outside synthetic data;
- test diagnostic stability across heterogeneous biomedical tasks;
- identify obviously degenerate representations.

Datasets:

```text
Golub
Colon
DLBCL
GDS2771
GSE10072
GSE17920
GSE19804
GSE25837
GSE27272
GSE3365
GSE6613
```

Labels are hidden from fitting and exposed only to the evaluation stage.

### Level 3 — frozen external transfer

Primary immediately available pair:

```text
source: GSE10072, lung adenocarcinoma versus normal, GPL96
target: GSE19804, lung cancer versus normal, GPL570
```

and the reverse direction.

The existing matrices contain:

```text
GSE10072: 107 samples, 22,283 probes
GSE19804: 120 samples, 54,675 probes
common probe IDs: 22,277
```

This is a technically demanding but immediately executable cross-study/platform-family test with clear evaluation labels.

Optional second pair, only if Level 3 is completed on time:

```text
GSE39582 → GSE14333 colorectal cancer
```

Both use GPL570, but their processed-value pipelines differ. This is scientifically more relevant to subtyping, but metadata/subtype-label harmonization makes it a second-stage dataset rather than the first pilot pair.

### Level 4 — direct regions and anchors

Purpose:

- test the actual methodological extension beyond generic clustering;
- compare post-hoc and direct region induction;
- test anchor restriction as a computational hypothesis.

Level 4 starts only after Levels 1–3 produce valid representation-audit results.

## 7. Source-only preprocessing

### 7.1 Common feature handling

For source→target experiments:

1. identify the common feature universe without using expression values or labels;
2. fit MAD ranking only in the source cohort;
3. select the top `p` source features available in the target;
4. freeze feature order;
5. apply the same feature list to every target sample.

Primary feature budget:

```text
p = 200
```

Sensitivity analysis:

```text
p = 500
```

The `p=500` analysis is not required for every simulation replicate.

For the primary matched comparison, every representation receives exactly the
same source-MAD-selected feature universe. This isolates the effect of the
representation. A relation-aware source-only feature screen may be evaluated
as a secondary ablation, but its result must not replace the matched comparison.

### 7.2 Value representation preprocessing

Primary value pipeline:

1. use already log-transformed values when documented;
2. source-only median imputation if needed;
3. source-fitted robust gene-wise scaling:

```text
z_g(x) = (x_g - source_median_g) / source_IQR_g
```

4. freeze medians, IQRs and fallback handling;
5. apply them unchanged to target samples.

No joint source-target scaling, ComBat, quantile normalization or target refitting is allowed in the primary transfer experiment.

### 7.3 Rank representation preprocessing

Within each sample, selected features are converted to normalized ranks:

```text
q_g(x) in [0, 1]
```

Ties receive equal/average ranks. Column order must not break ties.

### 7.4 Ternary relation states

For normalized rank margin `m`:

```text
+1  if q_i - q_j > m
 0  if |q_i - q_j| <= m
-1  if q_j - q_i > m
NA  if either feature is unavailable
```

Primary margins:

```text
m = 0.00
m = 0.02
```

`m=0.05` is a sensitivity setting, not part of the full grid.

## 8. Representation and method ladder

The primary comparison must keep the clustering engine fixed where possible. Otherwise, a difference between k-means and PAM would be incorrectly attributed to representation.

### 8.1 Matched representation baselines

| ID | Representation | Distance | Clustering |
|---|---|---|---|
| `V_EUC_PAM` | source-scaled values | Euclidean | deterministic PAM |
| `V_COR_PAM` | source-scaled values | correlation distance | deterministic PAM |
| `R_FOOT_PAM` | within-sample ranks | normalized Footrule | deterministic PAM |
| `R_PAIR_PAM` | selected ternary relations | masked weighted Hamming | deterministic PAM |

`R_KENDALL_PAM` is retained as a secondary verification method on small datasets. It is not run in every simulation because the current naive implementation is too expensive.

### 8.2 Standard algorithm baselines

Secondary only:

```text
k-means on source-scaled values
hierarchical Ward on source-scaled values
hierarchical average linkage on correlation distance
rank transform + ordinary k-means/PAM
```

These show whether conclusions depend on the matched PAM engine.

### 8.3 Hybrid distance baseline

Normalize source distance matrices using their source-only median nonzero pairwise distance:

```text
Dv_norm = Dv / median_source(Dv_upper)
Dr_norm = Dr / median_source(Dr_upper)
```

Then:

```text
Dh(alpha) = (1 - alpha) * Dv_norm + alpha * Dr_norm
```

Primary grid:

```text
alpha = 0.25, 0.50, 0.75
```

The primary hybrid combines `V_EUC_PAM` and `R_PAIR_PAM`. A Footrule hybrid is
a sensitivity analysis. This prevents an uncontrolled all-by-all grid of value
and relational distances.

Endpoints are represented by `V_*` and `R_*`. A hybrid is not considered successful merely because `alpha` is between zero and one. It must improve held-out source diagnostics and external transfer beyond both endpoints.

### 8.4 Candidate relation screening

For `p=200`, all 19,900 unordered pairs may be generated before screening.

Screening is source-only and unsupervised. A relation must satisfy:

- coverage above 0.90;
- sufficient state entropy/non-constancy;
- reproducibility under small source perturbations;
- no use of evaluation labels.

Primary retained relation budget:

```text
M = 2,000
```

Sensitivity:

```text
M = 500 and 5,000
```

A candidate score may combine entropy and perturbation stability, but its formula must be frozen before external labels are evaluated.

## 9. Deterministic PAM reference

The same PAM implementation must be used for value, relational and hybrid precomputed distances.

Required behavior:

- deterministic BUILD or deterministic farthest-first initialization;
- deterministic tie resolution by stable sample ID;
- swap/update iterations until no improvement;
- empty-cluster protection;
- returned medoid IDs and total objective;
- exact reproducibility from config and seed;
- exhaustive-optimum comparison on tiny golden datasets.

Random one-start medoids from the existing feasibility code are not sufficient for the primary experiment.

## 10. Simulation design

Each replicate creates a source and an independent target cohort with the same biological mechanism and a different nuisance transformation.

### 10.1 Primary dimensions

```text
n_source = 180
n_target = 180
p = 200
K = 3
informative features = 30
```

Sensitivity cases:

```text
n = 90 and 360
p = 500
unbalanced cluster proportions
```

### 10.2 Regimes

#### `VALUE`

- cluster-specific magnitude shifts on informative genes;
- shifts constructed to produce few or no informative rank inversions;
- target has moderate technical scaling/offset differences.

Expected winner: value representation.

#### `RELATIONAL`

- cluster-specific reversals of selected gene-pair orderings;
- weak absolute mean differences after marginalization;
- sample-wise monotone scaling and offsets between domains.

Expected winner: relational representation.

#### `HYBRID`

- one disjoint feature block carries magnitude signal;
- another block carries rank-reversal signal;
- neither block alone fully separates all clusters.

Expected winner: hybrid representation when both signals are sufficiently strong.

#### `NULL`

- no cluster-dependent biological signal;
- nuisance batch/domain structure may be present;
- the audit should not interpret nuisance structure as a stable biological clustering.

Expected output: `NO_STABLE_STRUCTURE`.

### 10.3 Nuisance/shift levels

```text
none
moderate
strong
```

Perturbations include:

- sample-wise affine/monotone transformation;
- gene-wise technical offsets;
- additive noise;
- random feature dropout;
- ties/quantization;
- missing target features.

Not every perturbation preserves relations. Gene-specific offsets and noise deliberately define cases where relational methods should also fail.

### 10.4 Signal levels and repetitions

For `VALUE`, `RELATIONAL` and `HYBRID`:

```text
signal = moderate, strong
shift = none, moderate, strong
30 replicates per cell
```

For `NULL`:

```text
shift = none, moderate, strong
30 replicates per cell
```

Total primary simulated source-target pairs:

```text
3 * 2 * 3 * 30 + 1 * 3 * 30 = 630
```

Before this full grid, run a 40-dataset smoke grid with five replicates per selected cell.

## 11. Representation Audit

The audit is computed on the source cohort only.

### 11.1 Diagnostics

For each representation/method and candidate `K`:

1. **Prediction strength (`PS`)**  
   Repeated source split, clustering on one part, frozen assignment of the held-out part, and comparison with held-out clustering.

2. **Cluster stability (`STAB`)**  
   Repeated 80% subsampling or bootstrap; all source samples reassigned to fitted medoids; agreement measured on a common sample universe.

3. **Perturbation invariance (`INV`)**  
   Agreement between baseline and realistically perturbed source clusterings.

4. **Non-degeneracy (`ND`)**  
   Minimum cluster size, normalized cluster entropy and absence of singleton/tiny clusters.

5. **Representation stability (`REP`)**  
   Stability of pairwise distance orderings and, where applicable, selected relation sets.

6. **Complexity (`COMP`)**  
   Number of retained features/relations and runtime. This is a tie-breaker, not the main quality metric.

Primary resampling count:

```text
B = 20
```

Smoke tests may use `B=5`.

### 11.2 Conservative audit quality

Avoid an arbitrarily weighted sum as the only criterion. Use:

```text
Q = min(PS, STAB, INV)
```

subject to non-degeneracy constraints.

Null simulations provide `K`- and sample-size-aware eligibility thresholds. A representation is eligible only when its `Q` exceeds the appropriate upper null quantile and it satisfies minimum cluster-size constraints.

### 11.3 Selection rule

1. Reject degenerate solutions.
2. Reject solutions not exceeding null-calibrated stability.
3. If no solution remains, return `NO_STABLE_STRUCTURE`.
4. Select the value or relational family with the largest eligible `Q`.
5. Select `HYBRID` only when its `Q` exceeds both best pure families by a null-calibrated minimum gain `delta_hybrid`.
6. When differences are below the equivalence margin, select the simpler pure representation.
7. Repeat the audit over outer source resamples and report the frequency of each decision.
8. Attach `UNCERTAIN` when no family reaches a predefined decision frequency, provisionally 0.60.

The thresholds, equivalence margin and `delta_hybrid` are calibrated on simulations and frozen before examining external target labels.

### 11.4 Output

```json
{
  "decision": "RELATIONAL",
  "decision_confidence": 0.75,
  "selected_method": "R_PAIR_PAM",
  "selected_k": 3,
  "selected_alpha": null,
  "q_score": 0.82,
  "null_threshold": 0.63,
  "eligible_alternatives": [],
  "rejection_reasons": {},
  "source_only": true
}
```

## 12. Fixed-`K` and unknown-`K` protocols

### Primary protocol: fixed `K`

Use known `K` in simulations and reference class count in real labeled benchmarks. This isolates the representation-selection question from the separate problem of estimating the number of clusters.

Class membership remains hidden.

### Secondary protocol: unknown `K`

On selected simulation cells and the external lung pair:

```text
K = 2,...,6
```

Select `K` jointly with representation using source-only `Q`, non-degeneracy and a preference for the smallest `K` within the equivalence margin of the best `Q`.

Unknown-`K` results are secondary in the preliminary study and primary in the full grant.

## 13. Frozen source→target transfer

After source audit and model fitting, freeze:

- common/source-selected feature IDs and order;
- value preprocessing parameters;
- rank/tie/missing-data policy;
- relation list and relation margins;
- value and relational distance scales;
- hybrid `alpha`, if used;
- `K`;
- source medoid IDs or relational regions;
- assignment/rejection thresholds;
- source diagnostic report.

For each target sample independently:

1. map available features;
2. apply frozen value preprocessing and/or within-sample rank encoding;
3. compute distance to source medoids/regions;
4. assign the closest cluster if coverage and confidence conditions are satisfied;
5. otherwise return `UNASSIGNED`;
6. never refit on the target cohort.

Target labels are unblinded only after all assignments and artifacts are saved.

## 14. Direct sparse relational regions

This is a conditional Level-4 method.

### 14.1 Region representation

For cluster `k`:

```text
P_k = {relation_id, expected_state, weight, core_or_optional}
```

Sample-to-region distance is the weighted proportion of violated, observable relations.

### 14.2 Post-hoc baseline

1. Fit relational PAM.
2. For each cluster, calculate within-cluster state prevalence and outside-cluster contrast.
3. Select the top `L` stable relations.
4. Stop without changing assignments.

Method ID:

```text
RR_POSTHOC
```

### 14.3 Direct iterative method

1. Initialize assignments with deterministic relational PAM.
2. Estimate cluster-specific relation states.
3. Score each relation by:

```text
within-cluster prevalence
minus outside-cluster prevalence
times source perturbation stability
times observable coverage
```

4. Select sparse profiles with redundancy control.
5. Reassign samples by weighted region-violation distance.
6. Update regions and repeat.
7. Stop when assignments and profiles are unchanged or after 50 iterations.
8. Resolve empty clusters deterministically using the worst represented sample.

Method ID:

```text
RR_DIRECT
```

Primary profile sizes:

```text
L = 10, 25, 50 relations per region
```

Redundancy control:

- penalize duplicate/reverse relations;
- cap excessive reuse of one gene;
- prefer a shorter profile within the source equivalence margin;
- store the full selection trace.

The direct method must be compared with `RR_POSTHOC`, not only with generic value clustering.

## 15. Anchor gate

Anchors are tested as candidate-space restriction, not assumed to be superior predictors.

### 15.1 Minimal anchor experiment

1. Select `q` source-only anchor candidates using:
   - high measurement coverage;
   - low tie rate;
   - perturbation stability;
   - nontrivial relation entropy across partners.
2. Generate only anchor-to-feature relations.
3. Apply the same candidate and final profile budgets as in the unrestricted method.
4. Compare runtime, candidate count, profile stability and external performance.

Primary values:

```text
q = 20 and 50
```

Methods:

```text
RR_DIRECT_ANCHOR20
RR_DIRECT_ANCHOR50
```

### 15.2 Anchor-set experiment

Do not start before single-anchor restriction passes its gate.

If it passes, test support sets of size 5 and 10:

```text
D(a,G) = fraction of g in G for which q_a > q_g + m
```

Use only a small predefined threshold grid:

```text
tau = 0.6 and 0.8
```

No unrestricted search over arbitrary anchor sets is allowed in the pilot.

## 16. Evaluation metrics

### 16.1 Primary simulation metrics

- representation decision accuracy for moderate/strong signal;
- `NO_STABLE_STRUCTURE` specificity under null;
- target ARI and NMI;
- selection regret:

```text
regret = target_score(oracle family) - target_score(selected family)
```

- source audit score versus target performance correlation;
- hybrid false-selection rate in pure `VALUE` and `RELATIONAL` regimes.

### 16.2 Primary real-data metrics

- ARI and NMI against labels, evaluation only;
- target coverage and unassigned fraction;
- source and target cluster-size distributions;
- assignment confidence/margin;
- source-to-target profile retention;
- source-to-target relation flip rate;
- runtime and peak memory.

### 16.3 Region-specific metrics

- number of relations per region;
- gene count and anchor degree;
- bootstrap Jaccard of selected relations;
- profile-state retention in target;
- mean violation rate in assigned versus non-assigned samples;
- overlap and unassigned rate;
- direct versus post-hoc external performance.

### 16.4 Secondary biological evaluation

Only after the primary protocol is frozen:

- pathway enrichment of genes used in stable profiles;
- association with known molecular subtype labels;
- association with clinical variables/outcome;
- manual interpretation of a small number of profiles.

Biological enrichment must not select the representation or tune the model.

## 17. Provisional GO/STOP criteria

Freeze final thresholds after smoke tests and before full/external evaluation.

### Gate A — implementation correctness

GO when:

- all golden tests pass;
- deterministic rerun produces identical artifacts;
- no target fit occurs;
- labels are absent from fit/audit interfaces;
- hybrid endpoints reproduce their pure representations;
- tie behavior is invariant to feature-column ordering.

### Gate B — representation audit on simulations

Provisional GO when, for moderate/strong signal:

- correct family selected in at least 70% of replicates;
- median target ARI regret is at most 0.05;
- null false-structure rate is at most 10%;
- hybrid is selected in at most 20% of pure-regime simulations;
- the difference in source audit scores correlates with the corresponding
  difference in target performance with Spearman rho of at least 0.40.

If exact family accuracy is lower but regret remains small, retain the audit but weaken claims about exact selection.

### Gate C — real external transfer

GO when:

- the selected representation is within 0.05 ARI of the retrospective oracle
  in at least one transfer direction and within 0.10 in the reverse direction;
- all decisions were stored before target labels were evaluated;
- target assignment coverage is at least 0.80;
- every assigned target cluster contains at least 10% of target samples.

Failure of one real pair is not sufficient to reject the scientific question, but it blocks strong preliminary claims.

### Gate D — direct relational regions

GO when `RR_DIRECT`, relative to `RR_POSTHOC`, achieves at least one of:

- external ARI/NMI improvement of at least 0.05;
- similar external performance within 0.03 with substantially shorter profiles;
- an increase of at least 0.10 in bootstrap Jaccard of selected relations;
- better target profile retention or rejection calibration.

### Gate E — anchors

GO when anchor restriction provides:

- at least 5-fold candidate/runtime reduction;
- external ARI loss no greater than 0.03;
- no material decrease in profile stability or target coverage.

Otherwise anchors are reported as a negative/conditional result and removed from the central grant claim.

## 19. Mandatory tests

### Representation correctness

- sample-wise strictly monotone transformation leaves rank representation unchanged;
- equal values remain ties after column permutation;
- reversing a pair reverses its encoded state;
- relation missingness is masked rather than treated as disagreement;
- Footrule is zero for identical rankings;
- hybrid `alpha=0` equals value distance;
- hybrid `alpha=1` equals relational distance.

### Leakage tests

- changing target values cannot change source-selected features;
- changing target labels cannot change any fitted artifact;
- changing evaluation labels cannot change assignments;
- source preprocessing parameters are identical before and after target loading;
- candidate relations are generated without label access.

### Clustering tests

- PAM objective is non-increasing over iterations;
- tiny datasets match exhaustive medoid optimum;
- no empty output clusters;
- deterministic tie resolution;
- identical configs yield byte-identical key JSON artifacts.

### Audit tests

- clear value simulation selects `VALUE`;
- clear relation simulation selects `RELATIONAL`;
- complementary simulation permits `HYBRID`;
- null simulation can return `NO_STABLE_STRUCTURE`;
- hybrid is not selected when it does not exceed both endpoints.

### Transfer tests

- target samples are processed one at a time with identical results to batch application;
- unavailable target genes trigger documented coverage behavior;
- target assignment does not modify the source artifact;
- result collection rejects incomplete or schema-invalid jobs.

### Explicitly not required before submission

- full direct hybrid-region optimizer;
- general meta-learning recommender trained on hundreds of datasets;
- multi-omics integration;
- federated learning;
- fuzzy relations;
- CUDA;
- web portal;
- exhaustive set-versus-set anchor search;
- a complete production package.

### Expected computational scale

The full simulation grid contains 630 source-target pairs. With four pure
representations, three primary hybrid weights and 20 audit resamples, the run
will require on the order of 80,000–100,000 small clustering fits. Distance
matrices should be cached within each source/perturbation job.

Provisional wall-time expectations on the existing 20–28 CPU-job server setup:

```text
golden tests and 40-dataset smoke grid: below 1–2 hours
full simulations without full Kendall: approximately 8–24 hours
eleven real within-dataset audits: approximately 2–8 hours
two lung transfer directions: below 1–2 hours after data are prepared
direct-region/anchor experiments: approximately 2–12 hours per selected case
```

These are planning estimates, not promises. The smoke grid must record runtime
and update the full-grid estimate before launch. If the projected simulation
run exceeds 36 hours, first reduce audit resamples from 20 to 10 for low-signal
cells; do not remove regimes or external-transfer directions.

## 23. How pilot results change the grant

### Strong positive outcome

If Gate B and Gate C pass:

- Representation Audit becomes the first scientific task and possibly the main novelty axis;
- direct relational regions remain the main new clustering family;
- hybrid models are conditional, selected only when justified;
- `NO_STABLE_STRUCTURE` becomes an explicit scientific outcome;
- anchor methods remain a separate efficiency/stability hypothesis if Gate E passes.

### Mixed outcome

If source diagnostics do not identify the exact family but have low regret:

- claim robust family ranking rather than exact automatic selection;
- present a representation adequacy map, not an automatic recommender;
- keep direct relational regions as the central method.

### Negative selection outcome

If the audit does not predict external winners:

- retain the comparative study of representation regimes;
- remove automatic-selection claims;
- focus SONATA on relational regions and transparent limits of applicability.

### Negative anchor outcome

- remove anchors from the title and main hypothesis;
- report them as an explored compression strategy;
- retain unrestricted sparse relation screening.
